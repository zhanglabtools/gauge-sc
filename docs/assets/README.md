# Documentation artwork

`application-*.svg` are the unnumbered original Figure 1c component drawings copied from the research project's `figures/fig1_conceptual_panels/`. Their labels are HTML, so each card can wrap responsively. They are schematics, not experimental readouts.

The full Figure 1b framework assembly has not been imported: its editable source is still needed to preserve its content while replacing ITCA-MDL with ITCA+ and removing the panel letter. No raster screenshot has been relabeled or presented as a vector original.

Concept PNGs are generated by `scripts/render_concept_assets.py` from the synthetic concept notebook.
