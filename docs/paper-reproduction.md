# Paper reproduction

The frozen-results bundle redraws 41 quantitative panels from saved experiment
outputs. It includes the plotting scripts, pinned Python dependencies and
data-access information. The HTML overview shows Figures 1–6. The individual
PNG and PDF files use the paper's panel IDs.

Download `gauge-frozen-results-v1.zip` from
[GAUGE Releases](https://github.com/zhanglabtools/gauge-sc/releases) and follow
the bundled `README.md`. The full replay uses a checksum-verified CosMx
metadata file from Bruker. The bundle includes a script to fetch it.

The validation report checks quantities such as ROC areas, candidate-selection
scores and hierarchy counts from the frozen tables. For a step-by-step example,
see [Reproduce Figure 4b–f](reproduce-figure4.md).
