# Paper reproduction

Redraw 41 quantitative panels from the frozen result tables. The HTML
overview shows Figures 1–6. Individual PNGs and PDFs use the paper's panel IDs.

- [Download and run the reproduction bundle](PUBLIC-README.md)
- [Data access, attribution and terms](DATA-SOURCES.md)

The bundle includes plotting scripts, Python dependencies and numerical
checks. The full replay also uses a CosMx metadata file from Bruker. The
[mixture audit tutorial](../notebooks/real_data/11_mixture_audit.ipynb) shows how
to run a related analysis with the GAUGE Python API.
